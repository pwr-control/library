# test — test bench of the 18 bridges

| File                                   | Content                                                                                    |
|----------------------------------------|--------------------------------------------------------------------------------------------|
| `test_semiconductors_bridges.slx`      | model: the 18 bridges in 18 test cells, in five groups driven by the five PWM modulators of `../../modulators` |
| `test_semiconductors_bridges_param.m`  | script that creates the struct `tb` (modulation, dc link, load, solver, device data)        |
| `test_semiconductors_bridges_run.m`    | script that simulates the model and checks every bridge; prints a PASS/FAIL table and plots |

## What the model contains

The root holds a `Clock` and five group subsystems, one per modulator: `modulator_hb` (the three
two-level half bridges), `modulator_1ph` (two-level full bridges), `modulator_3ph` (two-level
three-phase bridges), `modulator_1ph3L` (T-type full bridges, and the T-type half bridges through
a Bus Selector on `gate_cmds_ph1`) and `modulator_3ph3L` (T-type three-phase bridges). Each group
contains `phase = 0`, its sine modulation at `tb.f_out` with index `tb.m_amp` (as `m ∈ [−1, 1]`
for the single-phase modulators, as duty cycles `0.5 + 0.5·m` for the half-bridge and three-phase
modulators), the modulator with `f = tb.fpwm`, `dead_time = tb.dead_time`, `tc = tb.tc`, gate
levels `tb.gate_on` / `tb.gate_off`, and the test cells it drives. Comment out a group (right
click → *Comment Out*) to skip its bridges.

Each test cell `test_<bridge>` holds one bridge instance with its mask set from `tb.ideal`,
`tb.igbt` or `tb.mos`, a dc supply (one `tb.Vdc` source for the two-level full and three-phase
bridges; two `tb.Vdc/2` sources with the midpoint connected to `np` for the T-type bridges and
used as return for the half bridges), a series R-L load (`tb.load`, star connected with floating
star point for the three-phase bridges), a current and a voltage sensor, a *Solver
Configuration* with local Backward Euler solver at `tb.tc` and fixed-cost iterations
(`tb.nonlin_iter` for the two-level cells, `tb.nonlin_iter_ttype` = 20 for the T-type cells, see
the solver notes of the folder README), an *Electrical Reference*, and three
*To Workspace* blocks (`<bridge>_i`, `<bridge>_u`, `<bridge>_m`, sample time `tb.ts_log`).

Logged quantities: half bridges `i` and `u` of the leg against the dc midpoint; full bridges the
differential load current and voltage; three-phase bridges the phase-u current and the
line-to-line voltage u–v.

## Running it

MATLAB path: `semiconductors_bridges` with its subfolders, `../../modulators`,
`../../../foundation/semiconductors` (compiled `igbt_simple_2th_lib.slx`, `mos_simple_2th_lib.slx`).

```matlab
test_semiconductors_bridges_run
```

The script prints, for every bridge, the expected and simulated fundamental of load current
and voltage (tolerance 6 %, which covers dead time and device drops), the total mean losses and
the maximum junction temperature rise over the last fundamental period, and a verdict:

| Topology            | Expected fundamentals (`m = tb.m_amp`, `Z = |R + jωL|`)                 |
|---------------------|--------------------------------------------------------------------------|
| half bridge         | `U1 = m·Vdc/2` (vs midpoint), `I1 = U1/Z`                                |
| full bridge         | `U1 = m·Vdc`, `I1 = U1/Z`                                                |
| three-phase bridge  | `U1(line) = √3·m·Vdc/2`, `I1 = (m·Vdc/2)/Z`                              |

The 2th bridges pass when, in addition, the total losses are positive and finite and at least
one junction temperature rises. With the default `tb`, 800 V, 0.8 modulation index and a
2 Ω / 2 mH load, the load currents are about 150 A (half and three-phase) and 300 A (full
bridge), within the ratings of the default devices. Three fundamental periods (60 ms) at
`tc = 1 µs` take a few minutes; comment out the cells that are not needed to go faster.

The model was generated by `../tools/generate_test_model.py`. First results (2026-10-31, Davide):
the two-level cells pass with 5 nonlinear iterations (three-phase IGBT 2.6 kW and 17.6 K, MOSFET
374 W and 9.1 K at 148 A); the T-type MOSFET cell stopped at 0.9 ms with the junction temperature
below 0 K with 5 nonlinear iterations; it passes with 10, 20 and 50 (default 20).
